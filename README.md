## 📌 Project Overview

This project is an end-to-end **Agentic AI Financial Analysis System** built on top of a bilingual (English–Vietnamese) financial sentiment analysis framework. The system combines fine-tuned NLP models, a vector database, real-time market data APIs, and a large language model reasoning pipeline to provide structured stock analysis.

### Research Pipeline

**Phase 1 — Dataset Construction**

We constructed a bilingual financial sentiment dataset of ~100,000 samples: ~50,000 English financial headlines/sentences and ~50,000 parallel Vietnamese translations generated via LLM API (translation-augmentation). The dataset is publicly available on HuggingFace:

🗂️ **Dataset:** [finance-sentiment/financial-phrase-sentiment](https://huggingface.co/datasets/finance-sentiment/financial-phrase-sentiment)

**Phase 2 — Model Training & Benchmarking**

We fine-tuned and benchmarked multiple pre-trained language models on the bilingual dataset:

| Model          | Language                     | Link                                                                                                                                                |
| -------------- | ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Baseline**   | 🇺🇸 English and 🇻🇳 Vietnamese | [Baseline Notebook](https://github.com/hiIamShiba/financial-news-analysis-system/tree/main/notebooks/Baseline.ipynb)                                |
| **PhoBERT** ✅ | 🇻🇳 Vietnamese                | [finance-sentiment/phobert-vfa-sentiment](https://huggingface.co/finance-sentiment/phobert-vfa-sentiment)                                           |
| **RoBERTa**    | 🇺🇸 English                   | [finance-sentiment/roberta-financial-sentiment](https://huggingface.co/finance-sentiment/roberta-financial-sentiment)                               |
| **FinBERT** ✅ | 🇺🇸 English                   | [finance-sentiment/finetuned-FinBERT-sentiment-classification](https://huggingface.co/finance-sentiment/finetuned-FinBERT-sentiment-classification) |

After benchmarking, **FinBERT** was selected for English sentiment analysis in production and **PhoBERT-VFA** was selected for Vietnamese.

**Phase 3 — Agentic Application**

A multi-step agentic workflow was built that:

1. Retrieves the 10 most recent news articles for a selected stock ticker from a **ChromaDB** vector database
2. Runs **FinBERT/PhoBERT** sentiment analysis on each news item
3. Fetches **real-time stock price** (Finnhub API) and **30-day historical trend** (Yahoo Finance)
4. Calls **Llama 3.3 70B** (via Groq API) to perform a **13-step Chain-of-Thought** analysis framework based on:
   - **Eugene Fama** — Event Study Theory
   - **Paul Tetlock** — Financial Sentiment Theory
5. Presents all results in a **Streamlit** web dashboard

### Supported Tickers (Current Database)

`AAPL`, `MSFT`, `NVDA`, `GOOGL`, `AMZN`, `META`, `TSLA`, `BRK-B`, `LLY`, `V`, `JPM`, `WMT`, `JNJ`, `MA`, `PG`

> The system can be extended to support Vietnamese stocks by updating the ChromaDB database and switching to the PhoBERT model.

## ⚙️ Environment Setup

### Prerequisites

- Python **3.9+**
- `pip` package manager
- A GPU is optional but recommended for faster sentiment inference (CPU works fine)
- API accounts for **Groq** and **Finnhub** (both free tiers available)

### 1. Clone the Repository

```bash
git clone <your-repo-url>
cd <your-repo-folder>
```

### 2. Create a Virtual Environment (Recommended)

```bash
python -m venv venv

# Activate on macOS/Linux
source venv/bin/activate

# Activate on Windows
venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

> **Note on PyTorch:** If you have a CUDA-capable GPU and want GPU acceleration, install PyTorch with CUDA support from [pytorch.org](https://pytorch.org/get-started/locally/) before running the above command.

### 4. Configure API Keys

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_groq_api_key_here
FINNHUB_API_KEY=your_finnhub_api_key_here
```

**Obtaining API keys:**

- **Groq (free):** Sign up at [console.groq.com](https://console.groq.com) → API Keys → Create key
- **Finnhub (free):** Sign up at [finnhub.io](https://finnhub.io) → Dashboard → API Key

## 🚀 How to Run Inference

### Option A — Streamlit Web Dashboard (Recommended)

```bash
streamlit run app.py
```

Then open your browser at `http://localhost:8501`.

**Usage:**

1. Select a stock ticker from the sidebar dropdown
2. Click **"Run Strategic Analysis"**
3. Wait for the agent to complete analysis (~30–60 seconds)
4. View results: price chart, sentiment table, 12-step reasoning, bullish/bearish thesis, risk factors, and AI verdict

### Option B — Command Line

```bash
python main_agent.py
```

Enter a ticker when prompted (e.g., `AAPL`). The full reasoning and trading bias will print to the terminal.
